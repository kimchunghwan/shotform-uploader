개인정보처리방침

shotform-uploader는 운영자 본인만 사용하는 개인용 도구입니다.

  • YouTube Data API의 youtube.upload 권한만 요청하며, 운영자 본인 채널에 영상을 업로드하는 데에만 사용합니다.
  • Google 계정 인증 토큰은 운영자의 컴퓨터에만 저장되며 제3자에게 전송·공유하지 않습니다.
  • 다른 사용자의 개인정보를 수집·저장·판매하지 않습니다.
  • 권한은 Google 계정 권한 페이지에서 언제든 해제할 수 있습니다.

YouTube API Services를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

Privacy Policy

shotform-uploader is a personal tool used only by its operator. It requests only the youtube.upload scope to upload videos to the operator's own channel. OAuth tokens are stored only on the operator's computer and are never shared. No personal data of other users is collected, stored, or sold. Access can be revoked at any time from Google Account permissions. This tool uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy apply.
